# Atualizações — Lista App

O que mudou em cada versão, resumido em **uma linha + data**. Serve de guia do que
**re-testar** ao baixar uma versão nova. Mais recente no topo.

> Papéis dos arquivos (não confundir):
> - **`ATUALIZACOES.md`** (este) = changelog do usuário: o que mudou / o que testar.
> - **`APRENDIZADOS.md`** = diário técnico + lições (gotchas).
> - **`IDEIAS.md`** = planos futuros.
